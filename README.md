# liveryclub.com

The promotional website for [Livery](https://liveryclub.com), the digital garage for UK drivers.
The app itself lives at [app.liveryclub.com](https://app.liveryclub.com) (separate, private repository).

Plain HTML, CSS and a little JavaScript: no build step. Hosted on GitHub Pages from the `main`
branch; `CNAME` sets the custom domain.

- `index.html` – the page
- `style.css` – styles (brand tokens match the app)
- `main.js` – number plate box, header and key-date dials
- `fonts/` – self-hosted fonts (SIL Open Font License), so the site makes no third-party requests
- `assets/screens/` – screenshots of the app
